# Returns Policy

Returns are accepted within 30 days of delivery for a full refund, as long as the
item is unused and in its original packaging. Refunds go back to the original
payment method within 5-7 business days of us receiving the return.

## How to start a return

Returns don't require a phone call — start one from the order confirmation email,
using the order ID. An order that's still in transit (not yet delivered) can't be
returned yet; check its status with the order lookup tool first.

## Exceptions

Final-sale items and gift cards are not eligible for return. Everything else
follows the standard 30-day window.
